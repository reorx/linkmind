# LinkMind 项目状态 — 2026-02-18

## 项目概要
Telegram Bot 驱动的智能链接收藏分析工具。用户发链接给 Bot → 自动抓取、中文摘要、向量搜索相关内容、生成 insight。附带 Web 界面。

## 架构
pnpm monorepo: core（共享类型）+ server（Bot/Pipeline/Web）+ probe（本地抓取 daemon）
Tech: Node.js 22, TypeScript, Grammy, Express+EJS, PostgreSQL(Neon)+pgvector, Playwright+Defuddle

## 部署方式
macOS launchd user agent（本地 Mac Mini 运行）
